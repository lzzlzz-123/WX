# 隐私政策

**更新日期：2026 年 10 月 11 日**
**生效日期：2026 年 10 月 11 日**

欢迎使用「筑云清松」微信小程序（以下简称"本小程序"）。本小程序由【公司全称】（以下简称"我们"）运营。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。请您在使用本小程序前，仔细阅读并理解本《隐私政策》。

> 使用说明：本文档为上线用正式文本模板，发布前请将【公司全称】、【联系方式】、【公司注册地址】等占位内容替换为真实信息，并在微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」中同步配置。

## 一、我们收集的信息及用途

### 1.1 您授权我们收集的信息

| 信息类型 | 收集场景 | 用途 |
|---|---|---|
| 微信昵称、头像 | 登录/完善资料时经您授权 | 用于展示您的账户信息 |
| 手机号码 | 一键登录或验证码登录时经您授权 | 用于注册/登录账户、订单联络、配送通知 |
| 收货人姓名、电话、地址 | 您填写收货地址时 | 用于订单配送与售后服务 |
| 发票抬头、税号、邮箱 | 您填写发票信息时 | 用于开具与发送发票 |

### 1.2 您使用服务时我们自动收集的信息

- **日志信息**：为保障服务安全与排查故障，我们会记录接口访问日志（访问时间、IP、请求路径），日志保存期限不超过 6 个月。
- **交易信息**：您的下单、询价、购物车记录，用于履行合同、订单履约与售后。

### 1.3 我们不收集的信息

我们不会收集您的通讯录、精确地理位置、相册、剪贴板等与本服务无关的信息；不会将您的个人信息用于本政策未载明的用途。

## 二、信息的存储与保护

2.1 您的个人信息存储于中华人民共和国境内的服务器。
2.2 我们采用传输加密（HTTPS）、访问权限控制、密码加密存储等措施保护您的信息安全。
2.3 我们仅在实现目的所必需的最短期限内保留您的个人信息；账户注销后，我们将在 15 个工作日内删除或匿名化处理您的个人信息，法律法规另有规定的除外。

## 三、信息的共享、转让与公开披露

3.1 除以下情形外，我们不会向第三方共享您的个人信息：
- **微信开放平台**：登录鉴权所需的 code 交换（受微信隐私政策约束）；
- **物流配送**：为完成配送，向配送人员提供收货人姓名、电话、地址；
- **法律法规要求**：根据法律法规、诉讼或行政机关的强制性要求。

3.2 我们不会将您的个人信息转让给任何公司、组织和个人。
3.3 我们不会公开披露您的个人信息；如确需公开披露，将事先征得您的明示同意。

## 四、您的权利

4.1 **查询与更正**：您可在「我的 → 头像与昵称 / 收货地址 / 发票管理」中查询和更正您的信息。
4.2 **删除**：您可删除收货地址、发票抬头等信息；订单相关记录因履行法定义务需保留的除外。
4.3 **注销账户**：您可通过【联系方式】联系我们注销账户，注销后我们将删除或匿名化您的个人信息。
4.4 **撤回授权**：您可在微信「我 → 设置 → 个人信息与权限 → 授权管理」中撤回对本小程序的授权。

## 五、未成年人保护

本小程序面向企业采购场景，不面向未成年人提供服务。若您为未成年人，请在监护人指导下停止使用本小程序。

## 六、政策的更新

我们可能适时修订本政策。政策更新后，我们会在小程序内以弹窗或公告方式提示您，您继续使用即视为接受修订后的政策。

## 七、联系我们

如您对本政策或个人信息保护有任何疑问、意见或投诉，可通过以下方式联系我们：

- 客服电话：【联系方式】
